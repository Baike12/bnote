# 投资工作台业界调研（v2 改进依据）

> 来源：Google 检索 + 业界产品文档（2026-11）。作为第二轮改进（TODOS-v2.md）的设计依据，与三位盲测用户（交易员/分析师/量化）的报告交叉验证。

## 1. 布局与联动（master-detail synchronized multi-pane）

- Watchlist 是**主导航控制器**：点击/键盘切换标的时**所有 pane 同步更新**（左栏宽度惯例 20–25%）。
- 三栏分工惯例：左=导航与上下文树（自选/组合过滤、标的快切、上下文来源流）；中=thesis + 笔记画布；右=上下文感知 AI copilot。
- bnote 现状：三栏结构一致 ✓，但「标的切换联动」在 Agent 面板侧不完整（切标的时 agent 会话是否跟随 scope 需要验证）。

## 2. 键盘工作流（TradingView + 同花顺体系）

TradingView：
- 自选列表获得焦点后 **↓ 键逐个浏览标的**（看完一个 ↓ 进下一个，双手不离键盘）。
- **图表上直接打字母键呼出符号搜索**（无需点搜索框）。
- Alt+W 把当前标的加入自选；旗标颜色分类（7 色）。

同花顺（A 股本土惯例）：
- **↑/↓ 上下键直接切换股票**（列表、分时、K 线界面皆然）。
- K 线界面：**↑↓ 放大缩小，←→ 左右平移历史 K 线**。
- F5 分时/K 线切换、F8 周期切换、F10 公司基本面、F6 自选股、Insert 加自选 / Delete 删自选。
- **键盘精灵**：任意界面直接敲数字/字母代码 → 呼出标的搜索直达。

Bloomberg：
- **命令行是一切的入口**：函数助记符 + GO；Autocomplete 同时补函数与证券。
- 对应 bnote：⌘P 命令面板应能直达标的（敲 600519 → 切到该标的）与投资命令。

> 差距结论：bnote 的 ⌘⌥→/← 组合键太重；缺 ↑↓ 切股、缺图表打字搜索（键盘精灵）、K 线无 ←→/↑↓ 键位、无 F10/F5 式的一键切换到详情/图。

## 3. AI 投研助手形态（per-stock context）

- 从 stateless Q&A → **stateful thesis evolution**（"新的利润率数据对我的 Q3 多头逻辑有什么影响"）。
- **Thesis 层（结构化观点）**：3–5 个 bull/bear 支柱、盯防 KPI、目标价、**失效触发条件（kill criteria / thesis breakers）**。
- AI copilot 自动注入当前标的的 thesis + 用户笔记 + 选中文档。
- **Scoped context switching**：用户可切换 AI「看到」什么（只看我的笔记 / 最新财报+thesis / 全部历史上下文）。
- **Inline citations**：AI 的每个论断应链接到出处（文档段落 / 带日期的笔记）。
- Delta detection：新数据落地时自动 diff 旧笔记，标记矛盾。

## 4. 研究笔记组织（per-stock master note + 时间线日志）

- **单页 master note + 按时间倒序的研究日志**是最通行结构。
- Master note 模板：核心论点（电梯演讲）→ 关键数据 → 风险与 thesis breakers（pre-mortem）→ 研究日志（`### YYYY-MM-DD | 事件`，**Thesis Impact: Strengthened / Unchanged / Weakened**）。
- 元数据走 YAML frontmatter（Status / Conviction / Target price），可被查询。
- wikilinks 把每日市场笔记、板块研究连回 `[[标的]]` 页。
- 一个公司一个笔记本，**每条笔记回链出处**（Brief Equity 惯例）。

## 5. 回测指标口径（聚宽标准，业界通行）

- 年化收益：区间累计收益**复合**年化，扣除佣金与滑点；预热期/空仓期计入区间。
- 最大回撤：**相对历史净值峰值**的跌幅（非相对初始本金）。
- Sharpe：(年化收益 − 无风险利率) / 年化波动率；日收益 std × √252 年化。
- bnote 现状核对：backtest.rs 三项口径均符合 ✓（rf 2%、√252、rolling peak）。缺口：无基准对比（跑赢沪深300 吗）、无交易明细/净值曲线展示、无滑点参数。

## 6. 快照/盘口信息惯例（A 股）

- 同花顺/东财快照字段：涨跌停价、振幅、量比、委比、内外盘、五档盘口、总市值/流通市值、换手、量额。
- bnote 快照已有：价/昨收/开/高/低/量/额/换手/PE/PB/市值。缺口：**涨跌停价、振幅、量比、52 周高低**。

## 7. 对 bnote 的改进方向汇总（与盲测报告合并后写入 TODOS-v2）

1. 键盘工作流对齐业界（↑↓ 切股、键盘精灵、K 线 ←→/↑↓、F 系键位语义）。
2. 「导入数据」UI 入口（空态文案已承诺但无按钮）。
3. Thesis 结构（master note 模板 + 研究日志 + frontmatter 元数据）。
4. 快照字段补齐（涨跌停/振幅/量比/52 周高低）。
5. 回测增强（基准对比、净值曲线、交易明细、滑点参数）。
6. Agent 上下文增强（scope 切换跟随、上下文注入的可见性）。
